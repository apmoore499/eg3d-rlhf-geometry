# Public Release Test Outputs

This folder contains the tracked outputs from the maintained public release
verifier run.

These artifacts are intended to give readers concrete reference outputs for the
small end-to-end verification path without forcing them to reproduce the full
reported runs first.

## Included in Git

- `verification_summary.json`
  End-to-end verifier status summary, including the maintained reward-model
  forward tests and the released checkpoint test.
- `mesh_bank_test/`
  Tiny tuned-vs-untuned mesh-bank export for two seeds, using the maintained
  paper-facing `legacy_sigma10` geometry extraction path.
- `generated_data/triple_rgb_s_*.jpg`
  The six rendered RGB views for the two verification seeds.
- `generated_data/triple_dmap_s_*.pt`
  The two generated triple depth-map tensors.
- `generated_data/triple_rgb_lmks_98*.pt`
  The 2D and 3D landmark tensors derived from the rendered RGBs.

## Intentionally omitted from Git

These files were generated by the verifier, but are not tracked in the public
repo because they are the main contributors to binary history bloat while adding
little human-readable value:

- `generated_data/triple_rgb_s_28852_tensor.pt`
- `generated_data/triple_rgb_s_28853_tensor.pt`
- `generated_data/entire_sigma_field_256_s_28852.pt`
- `generated_data/entire_sigma_field_256_s_28853.pt`

If you want exact tensor-level reference artifacts for those files, package the
full verifier output directory as a GitHub Release asset instead of committing
it into normal git history.

## Regeneration

To regenerate this folder from the public mirror, run:

```sh
bash scripts/verify_public_release.sh /path/to/tuned.pkl
```

By default that wrapper writes back into `release_verification_outputs/` inside
this public worktree.
